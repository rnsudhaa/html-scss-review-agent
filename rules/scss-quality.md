# SCSS Quality Rules

## SCSS-NEST-001 — Limit Nesting Depth to 3
**Severity default:** major  
**Rationale:** Deep nesting increases specificity and reduces readability.

**Bad example**
```scss
.card {
  .header {
    .actions {
      .item {
        .icon { color: #111; }
      }
    }
  }
}
```

**Good example**
```scss
.card__icon { color: var(--color-text-strong); }
```

## SCSS-MOD-001 — Use `@use` Instead of `@import`
**Severity default:** major  
**Rationale:** `@use` prevents global namespace collisions and is the modern Sass module system.

**Bad example**
```scss
@import "tokens";
```

**Good example**
```scss
@use "tokens" as t;
.button { color: t.$color-primary; }
```

## SCSS-TOKEN-001 — Use Tokens for Color, Spacing, Typography
**Severity default:** major  
**Rationale:** Tokens improve consistency and simplify theme-wide changes.

**Bad example**
```scss
.badge { background: #005fcc; padding: 10px 14px; font-size: 13px; }
```

**Good example**
```scss
.badge {
  background: var(--color-brand-primary);
  padding: var(--space-2) var(--space-3);
  font-size: var(--font-size-sm);
}
```

## SCSS-MIXIN-001 — Use Mixins for Repeated Pattern Logic
**Severity default:** minor  
**Rationale:** Mixins reduce repeated declaration blocks and keep intent explicit.

**Bad example**
```scss
.card, .dialog, .toast {
  border-radius: .5rem;
  box-shadow: 0 2px 8px rgba(0, 0, 0, .12);
}
```

**Good example**
```scss
@mixin elevated-surface {
  border-radius: var(--radius-md);
  box-shadow: var(--shadow-sm);
}
.card { @include elevated-surface; }
```

## SCSS-PLACE-001 — Use Placeholders for Shared Rulesets
**Severity default:** minor  
**Rationale:** `%` placeholders avoid extra classes while enabling reuse via `@extend`.

**Bad example**
```scss
.btn-primary { display: inline-flex; align-items: center; }
.btn-secondary { display: inline-flex; align-items: center; }
```

**Good example**
```scss
%btn-base { display: inline-flex; align-items: center; }
.btn-primary { @extend %btn-base; }
.btn-secondary { @extend %btn-base; }
```

## SCSS-PREFIX-001 — Do Not Handwrite Vendor Prefixes
**Severity default:** minor  
**Rationale:** Manual prefixes are error-prone and should be generated by tooling.

**Bad example**
```scss
.box {
  -webkit-border-radius: 8px;
  border-radius: 8px;
}
```

**Good example**
```scss
.box { border-radius: 0.5rem; }
```
