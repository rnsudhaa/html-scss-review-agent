# html-scss-review-agent
AI-powered HTML &amp; SCSS code review agent using GitHub Copilot — project-aware reviewer for semantic HTML, accessibility, responsive behavior, SCSS quality, duplicates, reusability, and maintainability.

## React support
The reviewer also covers `*.tsx`, `*.jsx`, and `*.module.scss` files. The default React convention in this repository is TypeScript components with colocated CSS Modules written in SCSS.

### React review commands
- `/review-react-component`
- `/jsx-a11y-audit`
- `/review-css-modules`
